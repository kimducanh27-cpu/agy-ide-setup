Apply only to frontend, website, mobile-screen, component, design-system, interaction or visual-design tasks.

- Check workspace .agent/skills/impeccable/SKILL.md and then global ~/.gemini/config/skills/impeccable/SKILL.md.
- When installed, the primary agent follows the upstream Impeccable skill for design work; APES UI/UX reviewer remains independent and read-only.
