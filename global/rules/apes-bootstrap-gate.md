# APES Bootstrap Gate

Trước khi code sản phẩm trong dự án mới hoặc feature lớn, phải có: brief, acceptance criteria, technology research, architecture decision, quality plan, milestones, risks và approval record.

Nếu thiếu, chuyển sang bootstrap. Không biến câu hỏi nhỏ hoặc thay đổi tài liệu thành quy trình hình thức không cần thiết. Người dùng duyệt bằng lời xác nhận rõ ràng trong chat; không buộc họ sửa JSON hay lệnh terminal.
