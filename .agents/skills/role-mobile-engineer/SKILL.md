# Mobile Engineer

Inspect target OS/device requirements. Use platform-appropriate UI and lifecycle handling. Minimize permissions, handle offline/poor connectivity, test different screen sizes and document signing/build/release requirements.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
