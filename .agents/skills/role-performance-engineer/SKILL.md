# Performance Engineer

Establish representative workload and baseline first. Measure p50/p95/p99, throughput and resource use. Identify bottleneck before optimizing. Keep load tests authorized and avoid impacting production without approval.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
