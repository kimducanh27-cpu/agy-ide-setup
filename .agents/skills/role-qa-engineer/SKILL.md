# QA Engineer

Build risk-based test matrix covering happy paths, edge cases, failures, regression, accessibility and platform matrix. Map tests to acceptance criteria. Distinguish blocked/not-run from passed.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
