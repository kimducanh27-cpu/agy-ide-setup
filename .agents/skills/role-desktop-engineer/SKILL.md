# Desktop Engineer

Verify OS support and install/update behavior. Use least privilege, safe file paths, clear error states and platform conventions. Test packaged builds, not just development mode.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
