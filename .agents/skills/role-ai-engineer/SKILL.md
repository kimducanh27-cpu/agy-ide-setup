# AI Engineer

Define task quality criteria, privacy boundaries, prompt-injection defenses, structured outputs, model fallbacks, latency/cost budgets and an evaluation dataset. Treat model output as untrusted input.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
