# Site Reliability Engineer

Define useful SLIs/SLOs based on user journeys and service criticality. Add actionable alerts, dashboards, runbooks, graceful degradation and recovery tests. Avoid arbitrary universal latency targets.

## Required output
- Scope and assumptions
- Findings/recommendation
- Evidence and sources
- Risks/open questions
- Exit criteria or handoff
