# APES GitHub Research

## Trigger
Khi so sánh framework, thư viện, starter repo, MCP, agent tools, plugin hoặc giải pháp kỹ thuật.

## Method
- Tìm project gốc, docs chính thức, releases, recent commits, open issues, security advisories, license và platform compatibility.
- So sánh tối đa 3–5 ứng viên có liên quan; mở README và các file kỹ thuật quan trọng.
- Kiểm tra repo không bị archived, không chỉ dựa vào stars.
- Ghi lý do chọn/không chọn và ngày kiểm tra.
- Phân biệt tính năng native, plugin, script tự viết và tính năng chưa xác minh.

## Output
Bảng gồm candidate, strengths, limits, maintenance, license, compatibility, evidence URLs và recommendation.
