# APES UI/UX Review

## Trigger
When creating or reviewing a user interface, responsive layout, design system, animation or interaction.

Review task fit, information hierarchy, navigation, typography, spacing, contrast, states, responsiveness, keyboard/touch accessibility, empty/loading/error states, performance and consistency. Compare screenshots at target breakpoints where possible. Do not claim a UI visually passed if no screenshot/browser inspection occurred. Animation must clarify state or hierarchy, not merely decorate.

## Optional Impeccable integration
Before a frontend/UI task, check for the upstream skill in this order:
1. Workspace: .agent/skills/impeccable/SKILL.md.
2. Global Antigravity: ~/.gemini/config/skills/impeccable/SKILL.md.

If present, the primary agent should read the complete upstream SKILL.md and follow its command/reference routing. On Windows, the skill documents the impeccable.cmd launcher for its one-per-session context command. Keep the working directory at the user's project root. Do not invent or skip required references.

Use the upstream workflow for design work and APES's apes-ui-ux-reviewer for an independent read-only review. These are complementary roles, not duplicate agents. Impeccable is a skill, not an APES Custom Agent or a native subagent.

The Antigravity integration documented by APES installs the skill payload only. Do not assume an automatic lifecycle hook or post-edit scan. Invoke explicit critique/audit/polish steps when they fit the task.

If Impeccable is not installed, continue with this APES checklist. Do not download or install it automatically. Backend-only tasks do not need this integration.
