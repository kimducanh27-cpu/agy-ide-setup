# APES Project Bootstrap

## Trigger
Dùng khi bắt đầu dự án mới, mở workspace chưa rõ cấu trúc hoặc ch�ẩn bị một feature lớn.

## Procedure
1. Inventory workspace và git status; không sửa file ở bước này.
2. Ghi mục tiêu, người dùng, use cases, constraints, out-of-scope.
3. Chuyển yêu cầu thành acceptance criteria co thể tất khiểm thử.
4. Kích hoạt các role skill phù hợp: BA, Product, CTO, Architect, Researcher.
5. Nghiên cứu stack theo bằng chứng, không mặc định framework.
6. Tạo architecture/ADR, quality plan, milestone plan, risk register.
7. Chạy pre-code validation và trình bày báo cáo tiếng Việt.
8. Chờ user approval trong chat trước khi code sản phẩm.

## Outputs`docs/engineering/apes/00-project-brief.md` đết dế `06-approval.md` .

## Stop conditions
Dìng và hỏi khi có quết ệnh tỪ sự đổi, bảo mật, chi phí, dịch vụ bên ngoái, phạm ti đổi, thục hoặc deployment.
