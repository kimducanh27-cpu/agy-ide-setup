# APES Security Review

## Trigger
When handling authentication, authorization, secrets, user data, network APIs, storage, dependencies, deployment or security-sensitive changes.

Identify assets, trust boundaries, entry points and threats. Check least privilege, input validation, output encoding, safe error handling, secret storage, dependency provenance and logging/privacy. Use tools available in the project; report commands and versions. Never expose tokens in findings. Escalate unresolved high-impact risks to the user.
